MARUYAMA's PORTFOLIO

マルヤマ アスカのポートフォリオ

#website

#自主制作

コンセプト

自身の過去の作品を掲載したポートフォリオサイト。 淡い水色を基調とした爽やかでシンプルなデザイン。 作品の良さを潰さないように淡々とした印象を心がけた。 また自身の名前を元に、『丸 = 円形』をモチーフにして作成した。

使用ツール

Photoshop / Illustrator / XD
Visual Studio Code

制作期間

企画・設計 - 1週間
デザイン - 1週間
コーディング - 2週間
ブラッシュアップ - 1週間

ターゲット

企業採用ご担当者の方々。

目的

データ量の多い作品をまとめたポートフォリオを作成し、より直感的に簡単に閲覧できるものを作る。 企業の採用ご担当者の方に自身のことや作品の制作過程などを知ってもらい、一緒に仕事をするイメージを持っていただく。

課題点

動画やアルバムなどの作品のデータ量が多く、ファイルを圧縮して送信すると開くのに手間がかかってしまう。

工夫したところ

より詳しく見ていただきたい作品の詳細ページを作品一覧にまとめ、 動画作品やアルバムなどのデータ量が多い紹介ページはモーダルウィンドウを実装することで簡単に作品が閲覧できるように工夫した。

参考

・1冊ですべて身につくHTML&CSSとWebデザイン入門講座(SBクリエイティブ)
・ほんの一手間で劇的に変わるHTML&CSSとWebデザイン実践講座(SBクリエイティブ)
・動くWebデザインアイディア帳(ソシム社)

LITA CAFE

リタカフェ

#website

#自主制作

コンセプト

就労移行支援事業所にて、プログラミング学習用の素材を元に作成した架空のカフェのウェブサイト。 温かみのある、リラックスしたアットホームな雰囲気のカフェを想定して制作を行なった。

使用ツール

Photoshop / Illustrator / XD
Visual Studio Code / Dreamweaver

制作期間

情報収集・学習 - 2週間
デザイン・設計 - 2週間
コーディング - 2週間
ブラッシュアップ - 3週間

ターゲット

20代〜30代の年齢層

目的

架空のカフェサイトを制作し、ターゲットや目的などを決めてスキルを表明する。 カフェに来たお客様がゆったりと寛げるような、リラックスした雰囲気をWEBサイトで表現する。 お店の雰囲気や情報を知ってもらい、お店に来たいと思うようなWEBサイトに繋げる。

工夫したところ

店内の食べ物の写真やお店の雰囲気がわかりやすいように色使いや明るさを調整し、より食べ物が美味しそうに見えるように写真を加工した。 お店の雰囲気が伝わるように写真のスライドショーを流し、手書き風の文字フォントや紙素材の写真を背景に使用して素朴でゆったりした印象が持てるようにした。 ユーザーがポチッと押したくなるような楽しいボタンのデザインを他の飲食店などのHPを参考にしながら制作した。

使用サイト

https://unsplash.com/ja

参考

・1冊ですべて身につくHTML&CSSとWebデザイン入門講座(SBクリエイティブ)
・ほんの一手間で劇的に変わるHTML&CSSとWebデザイン実践講座(SBクリエイティブ)
・動くWebデザインアイディア帳(ソシム社)
